# Development

See [README.md](README.md) for setup, API behavior, and compatibility limits.

- Run `devenv shell -- bridge-check` to check code changes.
- Build with `devenv shell -- bridge-build`; generate release artifacts with `devenv shell -- bridge-release`.
- Keep credentials, local configuration, and generated artifacts out of version control.
- Preserve third-party license notices when updating dependencies or adapted code.
